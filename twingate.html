Twingate's Documentation Website (Before)

Problem

There seems to be added friction in an area that is supposed to reduce it. The documentation website was extremely cluttered, lacked text and information hierarchy to any extent and was difficult to navigate for someone coming to look for a particular guide / article.

1.1 — Twingate's Documentation Website (Before)
Research & Analysis

Process

Conducted a thorough competitive analysis of documentation platforms across the enterprise SaaS landscape. Mapped user flows and identified friction points in the existing navigation structure.

Redesigned Documentation

Outcome

A restructured documentation website with improved information hierarchy, clearer navigation patterns, and reduced cognitive load for users seeking specific guides and articles.
